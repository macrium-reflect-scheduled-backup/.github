## Troubleshooting Common Issues

Install issues? Confirm the destination is online at the scheduled time and that the service account can write to it.  
Performance problems? Move the backup window to idle hours and reduce compression on slow disks.  
License/activation? Check the license expiry date, since scheduled jobs stop when activation lapses.  
Compatibility? Recreate jobs after upgrading to a different major version to pick up new options.  
Update failures? Update from inside the app, then verify that the schedule survived the upgrade.
